### 1. Описание проекта

**«The Oracle That Wears Us»** — это интерактивная арт-инсталляция в формате аркадной машины внутри проекционно-маппинга палатки.  

Зритель подходит, нажимает кнопки или двигается перед камерой, говорит в микрофон.  
Оракул анализирует голос и движение → генерирует уникальный паттерн → роботизированный плоттер рисует его на ткани.  
Фрагменты ткани накапливаются и превращаются в коллективную носимую одежду.  

**Главная идея**: авторство переходит от дизайнера → машины → публики.  

**Ключевые компоненты**  
- Аппаратная часть: плоттер MKS TinyBee + FluidNC, аркадная консоль, проектор, камера, микрофон, громкоговоритель, монитор.  
- Программная часть: реал-тайм обработка голоса, генеративный ИИ, управление плоттером.  
- Результат: каждый зритель оставляет свой след на общей одежде.

**MVP (минимально жизнеспособный продукт)**  
Аркада → захват голоса/движения → генерация паттерна → плоттер рисует фрагмент ткани → фрагменты собираются в одну одежду.  

**Пул дополнительных идей** (реализуются только после успешного MVP и тестов):  
- Слоистая память  
- UV-скрытые паттерны  
- Эффект дегенерации  
- Коллективный порог  
- Символические подписи  

Проект гибкий: любые изменения по результатам исследований и тестов документируются в еженедельных отчётах.

### 3. Как работает таймлайн проекта (структура веток)

**Главная линия** — защищённая ветка `main` (только проверенный код).  
**Еженедельные линии** — временные ветки `week-XX-...`.  
**Личные линии студентов** — ветки вида `имя/задача`.  
**Крошечные спринты** — отдельные Issues внутри текущей недели.

**Еженедельный ритм** (гарантирует ежедневную видимую работу):  
- Понедельник — 10-минутная встреча, задачи в колонку «This Week».  
- В течение недели — ежедневные коммиты и маленькие PR.  
- Воскресенье 23:00 — автоматический PDF-отчёт через GitHub Action + Typst.  
- Понедельник утром — демонстрация отчёта и живого результата.

### 6. Основной технологический стек (2026)

**Центральный мозг** — TouchDesigner (бесплатная Non-Commercial версия)  
**Голос → текст** — Moonshine Tiny (26–34 МБ, задержка 34–70 мс на CPU, полностью локально)  
**Генеративный ИИ** — ComfyUI через ComfyTD (прямое управление workflow из TouchDesigner) + Qwen 2.5/3.5 0.8B/1.5B/4B (quantized GGUF) для умных ответов  
**Текст → голос** — Kitten TTS Nano (25 МБ, 8 выразительных голосов, полностью локально)  
**Управление плоттером** — MKS TinyBee + FluidNC (WiFi WebSocket, Python-middleware)  
**Дополнительно**: OSC, Python внутри TD, MediaPipe (камера), Audio Out (громкоговоритель), Spout/Syphon (монитор)

Всё работает локально, без облаков, на обычном ноутбуке.

## Contact & Collaboration

### Weekly Flow
1. **Monday:** Team meeting, issues moved to "This Week"
2. **During week:** Work in individual branches with tiny PRs
3. **Sunday night:** GitHub Action generates PDF report
4. **Monday morning:** Report + live demo to professor

### Branch Strategy
- `main` - Protected branch (stable, reviewed code)
- `week-XX` - Temporary branches for weekly goals
- `name/*` - Personal branches (e.g., `andrey/plotter-test`)

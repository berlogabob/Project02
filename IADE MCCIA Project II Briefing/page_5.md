# 4. PROJECT REQUIREMENTS
Within the context of the collaboration between the two master programs, the groups having the opportunity propose solutions and strategies for any undefined aspects of their project, but must comply with the following requirements:
• The team size is 2 students (exceptions only if needed);
• The prototype must be testable;
• Graphical and audio assets must be integrated.
